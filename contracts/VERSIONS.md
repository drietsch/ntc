# Contract Compatibility Matrix

Every cross-workstream contract is versioned here. A change to any contract
requires bumping its version **in the same PR** as the change, regenerating
affected artifacts (schemas, golden fixtures), and noting migration impact.
The `.ntc` metadata embeds the versions a model was built against; the runtime
refuses mismatches at load time.

| Contract | Version | Source of truth | Machine-readable artifact | Pinned by |
|---|---|---|---|---|
| `.ntc` file format | **1** | `crates/ntc-format` (normative reader) | `docs/model-format.md` | round-trip CI (Rust writer + Python `training/export/ntc_writer.py` → `ntc verify --dump-manifest` diff); corrupt fixtures `fixtures/ntc-format/` |
| Typed Action IR | **1** | `crates/ntc-core/src/ir/mod.rs` | `contracts/action-ir/v1/*.schema.json` (generated by `ntc gen-schemas`, drift-checked) | `fixtures/ir/{valid,invalid}` accept/reject parity (Rust serde + Python jsonschema) |
| Canonical Tool ABI + rendering | **1** | `crates/ntc-core/src/schema/mod.rs` (single implementation; Python via `ntc schemac`) | `contracts/tool-abi/v1/tool-abi.schema.json` | golden corpus `fixtures/schema-abi/*.{json,canon.txt}` byte-compare |
| Head codec (neural output ABI) | **1** | `contracts/heads/v1/head-spec.json` (jointly authored) | itself | tensor names/shapes checked by `ntc_model::weights::tensor_specs` + PyTorch `ntc_model` head names; tiny-model decision parity |
| Tokenizer artifact | *unfrozen* | `contracts/tokenizer/tokenizer.json` (absent until the pruned-vocab tokenizer is built — milestone B1) | sha256 embedded in `.ntc` header | golden vectors `fixtures/tokenizer/vectors.jsonl` (to be generated at freeze) |
| Architecture id | `ntc_encoder_heads_v1` | `crates/ntc-model` | `.ntc` metadata `architecture` | loader rejects unknown ids |

## Library version pins (train/serve parity)

| Library | Rust | Python | Why pinned together |
|---|---|---|---|
| HF tokenizers | `tokenizers = 0.21` (workspace) | `tokenizers` (training/pyproject.toml — keep on the same 0.21.x minor) | same Rust core; behavioral drift across minors would break golden vectors |

## Normative conventions (documented once, referenced everywhere)

- Linear weights in `.ntc` are **[in, out]** row-major; PyTorch exporters transpose.
- Spans are **token indices** `[start, end)` over the tokenized utterance; gold
  data stores char offsets; the collator converts via tokenizer offsets.
- Action classes `[CALL, ASK, NO_CALL]`, presence
  `[PRESENT, MISSING, AMBIGUOUS, NOT_APPLICABLE]` — orderings frozen in the
  head spec.
- Canonical text: NFC, whitespace-collapsed, lowercased, one trailing `.`
  stripped, 200-char cap; arg order = declaration order; `\n` separators, no
  trailing newline; no `ABI` line in the token stream (version lives in
  metadata).
