# Contract Compatibility Matrix

Every cross-workstream contract is versioned here. A change to any contract
requires bumping its version **in the same PR** as the change, regenerating
affected artifacts (schemas, golden fixtures), and noting migration impact.
The `.ntc` metadata embeds the versions a model was built against; the runtime
refuses mismatches at load time.

## Normative conventions (documented once, referenced everywhere)

- Linear weights in `.ntc` are **[in, out]** row-major; PyTorch exporters transpose.
- Spans are **token indices** `[start, end)` over the tokenized utterance; gold
  data stores char offsets; the collator converts via tokenizer offsets.
- Action classes `[CALL, ASK, NO_CALL]`, presence
  `[PRESENT, MISSING, AMBIGUOUS, NOT_APPLICABLE]` — orderings frozen in the
  head spec.
- Canonical text: NFC, whitespace-collapsed, lowercased, one trailing `.`
  stripped, 200-char cap; arg order = declaration order; `\n` separators, no
  trailing newline; no `ABI` line in the token stream (version lives in
  metadata).
